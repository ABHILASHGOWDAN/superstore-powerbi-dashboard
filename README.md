# superstore-powerbi-dashboard
n end-to-end Business Intelligence project built in Power BI, analyzing the classic Superstore retail dataset to uncover actionable sales, profit, and customer insights across regions, categories, and time periods.

Project Overview:
This dashboard transforms raw transactional retail data into an interactive, executive-ready reporting solution. It is designed to demonstrate proficiency in data modeling, DAX, and visual storytelling — key competencies for BI Analyst and Data Analyst roles.


Tools & Technologies:

Power BI Desktop — Data modeling, DAX measures, interactive dashboards
Power Query (M Language) — Data cleaning and transformation
DAX — KPI cards, YoY comparisons, running totals, calculated columns

📊 Dashboard Features

KPI Cards — Total Sales, Total Profit, Profit Margin %, Order Count
Trend Analysis — Monthly and yearly sales/profit line charts
Regional Breakdown — Map visual and bar charts by state/region
Category & Sub-Category Analysis — Waterfall and bar charts highlighting top/bottom performers
Segment Insights — Consumer vs. Corporate vs. Home Office comparisons
Discount Impact Analysis — Scatter plot of discount vs. profit margin
Drill-through & Bookmarks — Navigation between summary and detailed views
Conditional Formatting — Highlighting underperforming regions and products
